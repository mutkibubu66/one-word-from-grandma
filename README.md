## The word

> robut

The single word a grandma would text about AI. Not "robot" — "robut":
the typo she would actually make, warm and a little baffled, funny in
one word, clearly about robots/AI, and fresh rather than the obvious pick.

## Run it

```sh
node main.ts
```

This writes the word to `/output/entry.txt` (6 bytes: `robut` + newline),
valid UTF-8, well inside the 1–30 character gate — and prints it to stdout.
